# Master-s-Degree-project
Here I report my master's degree projects, both with code (MATLAB or Wolfram Mathematica) and theory.
This repository contains the following directories:
OSC: coursework about Optimization in Control Systems:
  -LAVORI MATLAB: projects in MATLAB
MOBD_Algorithms: algorithms implemented in MATLAB for static nonlinear optimization and Feedforward Neural Networks
Project_MRL: Motion Planning in an environment with obstacles for a 2 DOF planar robot by SARSA(\lambda) algorithm.
MGSC: project in Optimization for complex industrial systems:
  -Implementation of Heuristic "Shifting Bottleneck Algorithm" for Job Shop problem.
